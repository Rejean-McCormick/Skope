# Harmonized NEX-27 Glossary

The consortium discovered that several apparent scientific disagreements were definition disagreements.

- **case** — participant meeting PROT-001 v3 inclusion criteria.
- **recovery** — sustained return below the agreed symptom-impact threshold for two consecutive observations.
- **response** — prespecified change on the response composite; not synonymous with recovery.
- **significant** — must be qualified as statistical, clinical or operational.
- **confirmed** — remains contested; see Korum RQ-005.
- **relapse** — return above threshold after meeting the recovery definition.

Every analysis must cite the definition version it uses.
