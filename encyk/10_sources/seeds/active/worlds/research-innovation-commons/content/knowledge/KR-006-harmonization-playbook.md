# Five-Site Harmonization Playbook

1. Freeze the original definition and preprocessing rules.
2. Map differences explicitly rather than silently translating them.
3. Reclassify a blinded common case set.
4. Reconcile only differences that can be justified.
5. Preserve site-specific variables that may carry real information.
6. Version the harmonized protocol and data dictionary.
7. Re-run selected analyses using both original and harmonized pipelines.

Goal: interoperability without erasing meaningful heterogeneity.
