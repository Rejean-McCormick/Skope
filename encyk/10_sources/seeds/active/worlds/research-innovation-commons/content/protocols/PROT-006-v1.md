# PROT-006 v1 — Preregistered immune-response replication and robustness audit

**Status:** current. **Synthetic demo protocol.**

## Objective
Replicate the shared immune signature using frozen outcomes and expose which conclusions depend on plausible analysis choices.

## Inputs
- DATA-005 v1 active replication registry.
- DATA-006 v1 robustness matrix for completed analyses.
- Frozen primary outcome and sensitivity grid.

## Preregistration
Before the active result is examined, freeze inclusion rules, primary contrast, transformation, model family, and interpretation thresholds.

## Procedure
1. Register the primary analysis.
2. Run the primary analysis once after data freeze.
3. Run the declared sensitivity grid.
4. Separate confirmatory and exploratory outputs.
5. Record any deviation with reason and timestamp.

## Robustness rule
A headline claim is robust only when its direction and substantive interpretation survive the prespecified plausible-analysis set.

## Outputs
- RES-007 when the active replication completes.
- RES-010 robustness audit.
- Sensitivity matrix linking model choices to conclusions.

## Limitation
A robust association is not automatically a causal mechanism.
