# PROT-003 v1 — Independent KX-17 replication

**Status:** current. **Synthetic demo protocol.**

## Objective
Test whether the reported KX-17 association survives independent measurement, an external synthetic cohort, and prespecified analysis.

## Inputs
- DATA-002 v1 replication summary.
- Frozen assay calibration specification.
- Prespecified primary and sensitivity models.

## Independence rule
The replication analyst cannot alter the primary endpoint after viewing the replication outcome.

## Procedure
1. Calibrate the assay against the frozen reference.
2. Lock inclusion/exclusion criteria before analysis.
3. Run the primary model exactly once.
4. Run declared sensitivity analyses separately.
5. Report direction, magnitude, uncertainty, and deviations.

## Interpretation rule
Directional replication without stable magnitude supports association only; it does not establish causality.

## Outputs
- RES-003, RES-008, and RES-009 under different declared tests.
- Deviation log.
- Replication summary.

## Limitations
The synthetic intervention pilot tests one causal prediction under one set of conditions; a null result does not globally falsify every possible KX-17 mechanism.
