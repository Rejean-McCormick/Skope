# PROT-001 v2 — Mapped cross-site case definition

**Status:** superseded. **Synthetic demo protocol.**

## Objective
Map the five site-local definitions into a common vocabulary without yet forcing a single threshold.

## Inputs
- PROT-001 v1 definition inventory.
- Sixty synthetic reference cases.
- Cross-site disagreement inventory.

## Mapping rules
- Separate `response` from `recovery`.
- Label statistical and clinical significance separately.
- Preserve site-specific exclusions as explicit metadata.
- Record every mapping assumption.

## Procedure
1. Translate terms into the shared glossary.
2. Reclassify reference cases using mapped concepts.
3. Flag cases where disagreement persists because thresholds differ.
4. Review flags with clinical, data, and methods representatives.

## Analysis
Compare agreement with v1 and identify which disagreements disappear through semantics alone.

## Outputs
- Shared vocabulary map.
- Residual threshold disagreements.
- Candidate rules for blinded v3 classification.

## Limitations
A vocabulary map is not yet a frozen consortium case definition.

## Version note
Replaced by v3 after blinded testing showed which residual differences were operational rather than semantic.
