# Capstone — Design a Legitimate Institution

Le capstone demande à une équipe de transformer les tensions du World en une institution fictive cohérente. L'objectif n'est pas de trouver « la bonne philosophie », mais de montrer ce qu'une architecture résout, ce qu'elle sacrifie et quel désaccord elle laisse ouvert.

Chaque section du charter doit documenter : **choice**, **rationale**, **source_basis**, **alternative_considered**, **strongest_objection**, **response_or_unresolved_tradeoff**.

La version finale doit conserver un *minority report* lorsqu'un désaccord substantiel persiste. Un consensus de façade est moins bon qu'un désaccord correctement compris et documenté.
