# SCN-091 — Replay the Cyberattack Minute by Minute—Without Hindsight

> **Universal pattern —** Connect results, decisions, and causes into usable lessons learned.

> **Pattern family —** `PAT-19` Turn action into a lesson

## Situation

The post-mortem bans phrases like "we should have known." Every decision is evaluated using only the signals that were available when it was made.

## What is usually lost

Hindsight turns uncertainty into negligence when the historical state of knowledge is not preserved.

## With Koali

Koali rewinds the timeline to the signals actually visible at each decision, then carries lessons into owners, actions, and training without inventing hindsight.

## Loop

`timeline → state of knowledge → decisions → consequences → lessons → changes → future exercise`

## Usage palette

remember · understand · learn · organize

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●●●○○** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **timeline → … → future exercise** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

cybersecurity · emergency response · operations

The domain changes; the pattern remains: **Connect results, decisions, and causes into usable lessons learned.**
