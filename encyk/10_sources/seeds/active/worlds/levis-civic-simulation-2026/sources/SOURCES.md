# Sources — Lévis 2026

Ce catalogue accompagne le seed. Les textes de simulation sont des **paraphrases** des positions publiques; le JSON d'import contient le lien source sur chaque argument.

Règles :
- aucune position non documentée n'est complétée;
- les positions de campagne 2025 sont explicitement conservées comme historiques;
- une source journalistique est utilisée pour rapporter une déclaration ou un vote lorsqu'une source primaire facilement accessible n'est pas disponible;
- les questions de consultation du scénario sont créées pour la simulation et ne sont pas des consultations réelles de la Ville.
