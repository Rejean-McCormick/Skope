# Registre intellectuel actif

Ce dossier contient la partie du seed historique actuellement promue comme **entrée active** pour EncyKlopedia.

- `intellectuals.seed.json` : registre de 211 figures/personnes utilisé comme racines de résolution locale Wikidata.
- Les anciennes politiques de persona/eHok générées dans `historical-intellectuals-v0_1` ne sont **pas** promues ici : elles restent conservées sous `10_sources/seeds/originals/` comme provenance, car l'architecture retenue exploite les mécaniques existantes de Kristal/Konnaxion/eHok plutôt que de créer une politique parallèle.

Le registre actif peut évoluer par snapshots explicites. Le package original ne doit jamais être modifié silencieusement.
