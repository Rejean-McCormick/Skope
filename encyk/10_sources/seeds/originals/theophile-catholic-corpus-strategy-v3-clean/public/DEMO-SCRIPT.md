# Script de démonstration — 5 minutes

## 0:00 — Une phrase

> « Ce n'est pas un chatbot qui mémorise l'Église. C'est un corpus structuré que le chatbot consulte. »

## 0:30 — Question 1

**Tous les propos d'un pape ont-ils la même autorité ?**

Montrer :

- plusieurs statuts ;
- sources ;
- assertion sous-jacente.

## 1:45 — Question 2

**Compare Augustin et Thomas d'Aquin sur la liberté et la grâce.**

Montrer :

- auteurs séparés ;
- textes séparés ;
- synthèse comparative ;
- absence de fusion artificielle.

## 3:00 — Question 3

**Comment la pensée de Teilhard de Chardin a-t-elle été reçue par l'Église ?**

Montrer :

- position ;
- réception ;
- chronologie ;
- distinction entre citation favorable et approbation globale.

## 4:15 — Couper l'IA

Montrer brièvement la requête locale / JSON.

Phrase :

> « Si je retire le chatbot, le savoir structuré reste ici. »

## 4:45 — Conclusion

> « Une édition institutionnelle pourrait être gouvernée avec vos propres règles, indépendamment du moteur de conversation. »
