# Stratégie générale

## 1. Product-first, pas founder-first

Le corpus doit porter la première interaction.

Le courriel ne raconte pas une biographie. Il ne demande pas au destinataire de comprendre un univers de projets avant de juger l'objet présent.

Le produit démontre quatre choses immédiatement :

- il existe déjà ;
- il contient une masse substantielle de connaissances structurées ;
- ses affirmations peuvent être ramenées à des sources ;
- l'IA de conversation n'est pas l'autorité canonique.

## 2. Wedge product, pas « cheval de Troie »

Le terme interne correct est **wedge product** : une partie autonome d'une architecture plus large, qui résout un problème réel et peut être adoptée indépendamment.

Le langage de « cheval de Troie » est abandonné pour trois raisons :

- il suppose une intention cachée ;
- il fragilise la confiance si repris ou découvert ;
- il décrit mal la réalité technique : le corpus possède une valeur autonome réelle.

## 3. Montrer avant d'expliquer

Le premier destinataire doit pouvoir comprendre l'intérêt en quelques minutes.

Ordre recommandé :

1. courriel de 120 à 180 mots ;
2. lien direct vers une démonstration ;
3. trois questions préchargées ;
4. one-pager ;
5. téléchargement du corpus ;
6. documentation technique pour ceux qui veulent aller plus loin.

## 4. Souveraineté comme deuxième conversation

Le concept de souveraineté du corpus est central, mais il ne doit pas alourdir le premier contact.

Première formulation :

> « L'architecture permet au Saint-Siège de gouverner sa propre édition si cela lui est utile. »

Après intérêt : expliquer les branches institutionnelles, les politiques de validation, les signatures, les releases et la coexistence avec l'édition indépendante de Théophile.

## 5. L'Église n'adopte pas l'IA ; elle peut adopter un corpus

La distinction stratégique la plus importante :

```text
corpus canonique ≠ moteur de chatbot
```

Un fournisseur d'IA peut être remplacé. Le corpus demeure.

Cela réduit :

- le lock-in ;
- la dépendance à un modèle ;
- le coût de reconstruction du savoir ;
- le risque qu'une migration technologique efface le travail éditorial.
