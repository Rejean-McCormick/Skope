# Positionnement de Théophile

## Identité publique

**Théophile** est le nom d'usage public pour cette initiative.

Positionnement : **architecte de systèmes opérables**.

Coordonnées :

- https://www.theophile.systems/
- theophile.systems@gmail.com

## Voix

La voix doit être :

- directe ;
- littérale ;
- calme ;
- précise ;
- candide ;
- non cérémonielle ;
- non spectaculaire.

Elle évite le langage de permission inutile : « je me permets », « avec tout le respect que je vous dois », « humblement », etc.

Elle évite aussi le langage de grandeur : « révolutionnaire », « civilisationnel », « sans précédent », « futur de l'Église ».

## Forme de candeur recherchée

Dire :

> « J'ai construit ceci. Voici ce qu'il fait. Voici ce que vous pouvez vérifier. »

Ne pas dire :

> « J'ai peut-être fait quelque chose qui pourrait éventuellement vous intéresser. »

## Rapport à l'identité civile et aux projets antérieurs

Le premier paquet est centré sur le corpus et signé Théophile.

On ne donne pas spontanément l’historique de projets extérieurs au corpus, parce qu’il n’est pas nécessaire pour vérifier l’artefact.

Si une personne demande explicitement l'identité, la provenance ou l'historique du framework, la réponse doit être exacte et sans théâtre de révélation.
