# Funnel d'approche

## Étape 1 — Courriel

Objectif : obtenir un clic ou un transfert interne.

Le courriel doit tenir en environ 120–180 mots.

Il contient :

- « j'ai construit » ;
- une phrase sur ce que le corpus distingue ;
- une phrase sur le fait que le corpus est indépendant du moteur d'IA ;
- un lien vers la démo ;
- un lien vers le one-pager / corpus ;
- une invitation simple à transmettre à la bonne personne.

Il ne contient pas :

- l’historique de projets extérieurs au corpus ;
- une théorie générale de la souveraineté ;
- une longue défense de l'IA ;
- un débat sur Teilhard ;
- une autobiographie ;
- une liste de revendications.

## Étape 2 — Démo en trois questions

La démo doit fournir des exemples préchargés qui montrent la différence avec un chatbot ordinaire.

Questions recommandées :

1. **Tous les propos d'un pape ont-ils la même autorité ?**
2. **Compare Augustin et Thomas d'Aquin sur la liberté et la grâce.**
3. **Comment la pensée de Teilhard de Chardin a-t-elle été reçue par l'Église ?**

Chaque réponse doit :

- distinguer les positions ;
- afficher le statut ;
- citer les sources ;
- permettre d'ouvrir les assertions sous-jacentes ;
- dire « non trouvé dans le corpus » plutôt que combler un trou par invention.

## Étape 3 — One-pager

Le one-pager répond à :

- qu'est-ce que c'est ;
- pourquoi ce n'est pas juste un chatbot ;
- comment la qualité est contrôlée ;
- pourquoi c'est léger et portable ;
- ce que pourrait être une édition institutionnelle.

## Étape 4 — Archive

Le destinataire technique peut télécharger :

- Markdown ;
- état sémantique ;
- index ;
- outils de requête ;
- validateurs ;
- documentation ;
- métadonnées de provenance.

## Étape 5 — Conversation compétente

La première personne réellement utile peut être :

- théologien ;
- historien ;
- bibliothécaire / archiviste ;
- ingénieur ;
- responsable de culture numérique ;
- responsable de communication.

On ne force pas une seule route organisationnelle.

## Étape 6 — Édition institutionnelle

Seulement après intérêt concret : proposer une édition séparée, gouvernée par des personnes mandatées par l'Église, avec ses propres politiques éditoriales et de publication.
