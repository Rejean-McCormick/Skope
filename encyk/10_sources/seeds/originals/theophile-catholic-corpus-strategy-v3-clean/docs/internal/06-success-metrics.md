# Mesures de succès

## Premier contact

Le succès n'est pas mesuré par la stature du répondant.

Signaux utiles :

- ouverture de la démo ;
- téléchargement de l'archive ;
- lecture du README technique ;
- question sur une source ;
- demande de clarification sur le modèle doctrinal ;
- transfert interne ;
- demande d'une démonstration ;
- question sur une édition institutionnelle.

## Démo

Mesurer si l'utilisateur peut, en moins de cinq minutes :

- comprendre que le corpus et le chatbot sont séparés ;
- ouvrir une assertion ;
- voir une source ;
- comprendre pourquoi deux auteurs peuvent être juxtaposés sans être fusionnés ;
- distinguer dogme, enseignement, opinion et réception.

## Conversation avancée

Succès : obtenir un interlocuteur qui accepte d'évaluer une question concrète :

- qualité doctrinale d'un sous-corpus ;
- qualité des métadonnées ;
- déploiement local ;
- politique de traduction ;
- gouvernance d'une branche institutionnelle.

## Ce qui n'est pas nécessaire

- réponse personnelle du pape ;
- approbation générale du projet ;
- adoption d’autres produits ou architectures ;
- reconnaissance de Théophile comme figure publique.
