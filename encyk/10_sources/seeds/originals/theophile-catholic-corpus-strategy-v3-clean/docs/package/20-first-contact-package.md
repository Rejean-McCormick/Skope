# Paquet de premier contact

## Surface recommandée

Le premier paquet doit être petit.

### 1. Courriel

Très court. Aucun fichier lourd attaché si un lien propre est disponible.

### 2. Démo

Page simple avec :

- trois questions préchargées ;
- zone de question libre ;
- sources visibles ;
- bouton « voir les assertions » ;
- lien « télécharger le corpus ».

### 3. One-pager

Une page lisible sans contexte.

### 4. Archive

Nom neutre recommandé :

`corpus-intellectuel-catholique-v0.2.zip`

ou

`catholic-intellectual-corpus-v0.2.zip`

## Ce qui n'entre pas dans le premier paquet

- stratégie interne ;
- documents étrangers au corpus ;
- manifestes ou programmes sans rapport direct avec le corpus ;
- projets politiques ;
- longs textes autobiographiques ;
- présentations générales de l'écosystème.

## Ce qui reste accessible après intérêt

- note technique ;
- modèle de gouvernance ;
- architecture sémantique ;
- pipeline de validation ;
- historique et provenance complète ;
- proposition d'édition institutionnelle.
