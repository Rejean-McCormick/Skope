# Checklist de la démo

## Expérience

- [ ] La page explique le projet en moins de 60 mots.
- [ ] Trois questions préchargées sont visibles.
- [ ] Une réponse apparaît rapidement.
- [ ] Les sources sont visibles sans ouvrir une documentation séparée.
- [ ] Le statut de chaque position est visible.
- [ ] On peut ouvrir l'assertion sous-jacente.
- [ ] Le modèle peut répondre « non trouvé ».
- [ ] Aucun texte ne laisse croire que le chatbot parle officiellement au nom de l'Église.

## Technique

- [ ] Les réponses sont grounded dans les résultats récupérés.
- [ ] Les identifiants du corpus sont conservés.
- [ ] Les citations pointent vers des sources / locateurs stables.
- [ ] Les logs distinguent sortie du modèle et contenu canonique.
- [ ] Le moteur IA peut être remplacé.
- [ ] Le corpus est téléchargeable indépendamment.

## Confiance

- [ ] Signature Théophile visible.
- [ ] Contact visible.
- [ ] Provenance technique disponible.
- [ ] Aucun branding parasite.
- [ ] Aucun claim « officiel Vatican ».
