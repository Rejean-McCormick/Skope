# Nommage et identité de distribution

## Identité publique

La distribution institutionnelle utilise **Théophile** comme identité publique du bâtisseur.

Le corpus doit être présenté sous un nom descriptif et autonome, par exemple :

- `corpus-catholique` ;
- `corpus-intellectuel-catholique` ;
- `corpus-catholique-theophile`.

Le nom doit décrire l’objet livré, pas l’historique d’autres projets.

## Nommage technique

Les fichiers, schémas, namespaces, commentaires de code et métadonnées de la distribution doivent utiliser une terminologie générique ou l’identité Théophile.

Exemples :

- `corpus-semantic.schema.json` ;
- `corpus-catholique.semantic.json` ;
- `urn:theophile:source:...` ;
- `theophile.semantic-corpus.v1:jcs-rfc8785`.

## Principe

La distribution doit pouvoir être évaluée comme un objet autonome. Les noms et métadonnées doivent donc être cohérents avec le produit présenté et ne pas créer de dépendance contextuelle inutile.

La provenance publique reste exacte : **Théophile** est le nom d’usage et le point de contact de cette distribution.
