# Multilingue et traduction

## Pourquoi la structure aide

Un corpus structuré permet de traduire des unités identifiables plutôt qu'une masse opaque de poids de modèle.

Une traduction peut être reliée à :

- l'assertion source ;
- la langue ;
- la version ;
- le traducteur ou moteur ;
- le statut de revue ;
- l'édition originale ;
- les divergences lexicales importantes.

## État actuel

L'édition v0.2 est principalement en français.

Des sources dans d'autres langues ont été paraphrasées, mais les originaux grec, latin, espagnol ou autres ne sont pas systématiquement collationnés.

Il ne faut donc pas revendiquer que le produit est déjà « meilleur multilingue » qu'un grand modèle.

## Ambition démontrable

Le bénéfice architectural est :

> **traductions explicites, versionnables, inspectables et révisables.**

## Roadmap

1. identifiants stables par assertion ;
2. champs de langue explicites ;
3. conservation du texte/source original lorsque les droits le permettent ;
4. traduction machine candidate ;
5. validation terminologique ;
6. publication des variantes ;
7. benchmark de fidélité sur un échantillon théologique difficile.
