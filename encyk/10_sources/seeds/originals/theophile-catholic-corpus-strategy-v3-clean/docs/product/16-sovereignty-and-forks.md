# Souveraineté et forks

## Principe

Le corpus est conçu pour permettre plusieurs éditions légitimes sans fusion forcée.

Exemple :

```text
sources publiques / communes
          ↓
   base structurée
      ↙       ↘
Théophile   édition institutionnelle
édition      du Saint-Siège
```

## Édition institutionnelle

Une branche gouvernée par l'Église pourrait décider :

- sources privilégiées ;
- autorités de validation ;
- classifications doctrinales ;
- politique de traduction ;
- politique d'inclusion ;
- politique de release ;
- signatures ;
- corrections et errata ;
- interfaces officielles.

## Édition indépendante

Théophile conserve le droit de :

- poursuivre la recherche ;
- élargir le corpus ;
- expérimenter ;
- publier sa propre édition ;
- partager les résultats de son travail sous les droits applicables.

## Coexistence

La divergence n'est pas un échec.

Une édition institutionnelle peut être plus normative. Une édition indépendante peut être plus exploratoire.

Les deux peuvent partager une structure, des identifiants, des sources ou des corrections sans partager la même politique éditoriale.

## Formulation pour le Vatican

> « Si le Saint-Siège souhaite gouverner une édition propre, l'architecture le permet sans dépendre de mes choix éditoriaux futurs. »
