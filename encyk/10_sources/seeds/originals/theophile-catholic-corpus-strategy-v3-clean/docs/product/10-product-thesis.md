# Thèse produit

## Le problème

Une tradition intellectuelle de près de deux millénaires ne se laisse pas représenter correctement par une seule réponse générée.

Un assistant générique peut mélanger :

- la citation d'un auteur ;
- une paraphrase ;
- une doctrine officiellement définie ;
- une opinion théologique ;
- une réception historique ;
- une reconstruction moderne.

L'aisance linguistique ne garantit pas la provenance.

## La proposition

Construire une couche de connaissance où les unités sont structurées avant la conversation.

Une position doit pouvoir conserver :

- auteur / instance ;
- source ;
- localisateur ;
- contexte ;
- statut documentaire ;
- statut doctrinal lorsqu'il est établi ;
- réception ;
- relations avec d'autres positions ;
- version ;
- provenance.

## Résultat

Le chatbot n'a plus besoin d'inventer l'architecture du savoir à chaque question.

Il peut rechercher des unités déjà organisées et les juxtaposer.

Le produit devient alors :

> **une mémoire intellectuelle gouvernable, à laquelle plusieurs interfaces peuvent se connecter.**
