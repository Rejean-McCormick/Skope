# 20_evidence

Outgoing source evidence and handoff material.

Typical generated content:

- `scope-snapshots/<scope>/<snapshot>/` — complete selected source records, frozen losslessly;
- `identity-candidates/<scope>/` — source-qualified external identity hints, not Kristal identities;
- `handoffs/mediatheque/<scope>/` — `encyk.source-evidence-handoff/2.0.0` bundles;
- `manifests/` and `provenance/` — acquisition/source verification metadata.

This zone is **not a canonical long-term source store**. Once accepted, durable bytes/snapshots/representations belong to Médiathèque kOA. Retention here is for retry/audit policy only.
