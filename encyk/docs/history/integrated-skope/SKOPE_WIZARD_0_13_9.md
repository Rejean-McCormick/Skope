# Wizard de configuration Skope (0.13.9)

- **Ouvrir** : `✦ Wizard` dans l'en-tête ; le reste de Skope est inchangé.
- **Choisir le profil** : botanique prudent pour `Kristal-Botany`, ou exploration plus large sur demande.
- **Comprendre** : description et conséquence de chaque champ + graphe schématique sans chiffrage.
- **Appliquer** : chaque ligne se renseigne par un clic explicite ; le bouton global applique le profil d'un coup.
- **Mesurer** : comparer les compteurs actuels (si frais) avec un rapport calculé sur SQLite en lecture seule.
- **Évaluer la troncature** : 300/300 avec troncature ne constitue pas un périmètre exhaustif.
- **Après application** : `Calculer le périmètre` dans Skope ; pas d'export canonique automatique.

Les exemples taxonomiques (P171, P279) sont des recommandations de cadrage, pas des preuves ni
un substitut à l'extraction des déclarations complètes depuis le dump.

**Limitations** : rien n'a été testé contre le vrai index de 125 Gio et l'installation Windows locale.
