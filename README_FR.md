# Skope 1.0 RC1 — recherche et acquisition unifiées

Skope réunit la recherche Wikidata, la sélection des périmètres, la revue des identités, les extractions de preuves et le moteur EncyK de préparation des transmissions à Médiathèque kOA.

- Lancer `Start_Skope.cmd` puis ouvrir `http://127.0.0.1:8767`.
- Pour le gestionnaire EncyK avancé, vérifier **explicitement** les jonctions de données avant `Start_EncyK_Manager.cmd`.
- Le contenu sur `D:\EncyKlopedia` reste en place; aucune migration automatique des données.
- Portfolio est toujours accessible et les approbations humaines ne sont pas contournées.

Lire [`README_FUSION_1_0_FR.md`](README_FUSION_1_0_FR.md) pour l'installation et les limites de cette RC; [`docs/README_FR_STANDALONE_ARCHIVE.md`](docs/README_FR_STANDALONE_ARCHIVE.md) conserve les instructions historiques des versions antérieures.
